# СЛОВО — 乌克兰语单词学习网页应用

适合中文学习者的 A2–B1 乌克兰语词汇应用，内置 154 个单词、12 个生活与工作主题。

## 功能
- 乌克兰语 / 中文双语单词卡、例句和翻面记忆
- 使用浏览器 SpeechSynthesis 的乌克兰语发音（uk-UA）
- 间隔复习和记忆程度评价
- 翻译选择、拼写测验、收藏与词库搜索
- 自定义词汇及 JSON 学习记录备份和导入
- 响应式手机和桌面界面、渐进式网页应用（PWA）

## 本地打开
直接下载并打开 [standalone.html](./standalone.html) 即可体验，应用本身不需要联网。部分手机文件预览不会执行 JavaScript，建议使用浏览器打开。

## 网站部署
将本目录的所有文件一起部署到 HTTPS 静态主机（GitHub Pages、Cloudflare Pages 或 Netlify）。入口为 `index.html`。启用 HTTPS 后支持服务工作线程缓存，首次加载后可离线打开。若直接把本目录作为站点根目录，访问网址根路径即可。

在现有 `chinese-ua` 仓库中，本项目位于 `apps/slovo/`，与原中文教学站点相互独立；**添加代码不会自动让主域名提供新网页**，需另行配置静态资源发布路径。

## 进度与隐私
学习进度保存在浏览器本地存储中，不会自动云同步。换手机或清理浏览器前，请在「我的词汇」中导出 JSON 备份。

## 发音
设备需要支持 `uk-UA` 语音，具体效果依系统和浏览器已安装的语音而定。
