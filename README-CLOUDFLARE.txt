CHINESE-UA.PP.UA — CLOUDFLARE PAGES

1. Open Cloudflare.
2. Go to Compute -> Workers & Pages.
3. Create application / Pages / Upload assets (Direct Upload).
4. Upload this ZIP file, or unzip it and upload the folder.
5. Project name: chinese-ua
6. Deploy.
7. Open the generated *.pages.dev address and check the site.
8. In the Pages project open Custom domains.
9. Add: chinese-ua.pp.ua
10. Wait until the custom domain status becomes Active.

This is a fully static first version. No database or paid service is required.

DEVELOPMENT AND VERIFICATION
See README.md for local preview, browser checks, and speech limitations.
Upload only index.html, styles.css, script.js, and favicon.svg together.
Do not include .git, tests, or developer documentation in a manual upload.
