# Chinese UA

Статичний сайт для українців, які починають вивчати китайську мову.
Основний домен: https://chinese-ua.pp.ua/.

## Файли

- `public/index.html` — зміст українською; китайські приклади з піньїнем і перекладом.
- `public/styles.css` — адаптивні стилі та доступність.
- `public/script.js` — меню, синтез мовлення та копіювання.
- `public/favicon.svg` — іконка.
- `public/robots.txt` і `public/sitemap.xml` — інструкції для пошукових роботів і карта сайту.
- `tests/browser.cjs` — перевірки браузера, не потрібні для роботи сайту.

## Локальний перегляд

Запустіть `python -m http.server 8000 --directory public` у корені та відкрийте
http://localhost:8000. Збірка й залежності для сайту не потрібні.

## Перевірки

`node --check public/script.js` перевіряє синтаксис JavaScript.

Для `node tests/browser.cjs` потрібні Node.js, доступний пакет Playwright
і встановлений Microsoft Edge. Playwright є лише інструментом розробника:
він не завантажується на сайт. Якщо пакет встановлено окремо, задайте
`NODE_PATH` до його каталогу `node_modules`.

Тест запускає тимчасовий HTTP-сервер і перевіряє ресурси, внутрішні посилання,
10 ширин екрана (320–1440 px), збільшений текст, меню, копіювання,
стани синтезу мовлення та сторінку без JavaScript. Знімки екрана зберігаються
в тимчасовому каталозі системи. Сервер і браузер закриваються після тесту.

Синтез мовлення залежить від установленого китайського голосу та браузера.
Автотест окремо повідомляє результат справжнього виклику синтезатора;
успішна перевірка обробки помилки не означає, що звук відтворився.
Перед публікацією прослухайте обидві фрази на телефоні та комп’ютері,
перевірте зупинку й повторне відтворення. Без голосу сайт показує пояснення.

Копіювання використовує Clipboard API на HTTPS або localhost.
Якщо доступ заборонено, текст виділяється для ручного копіювання.

## Cloudflare Workers

Worker: `red-breeze-15ec`.
Конфігурація: `wrangler.jsonc` у корені; статичні ресурси: `./public`.
Сайт не потребує збірки. Усі чотири файли залишаються поруч, тому URL
`/styles.css`, `/script.js` і `/favicon.svg` не змінюються.
Документація та тести розташовані поза каталогом публікації.

## Google Search

Після публікації перевірте `https://chinese-ua.pp.ua/robots.txt` та
`https://chinese-ua.pp.ua/sitemap.xml`. У Google Search Console додайте
властивість `https://chinese-ua.pp.ua/`, підтвердьте право власності,
подайте `sitemap.xml` і перевірте головну сторінку через URL Inspection.
Після цього можна попросити індексацію. Подання карти сайту й запит на
індексацію не гарантують появи сторінки в результатах пошуку.

Для автоматичного розгортання потрібне підключення цього GitHub-репозиторію
до Worker у Cloudflare з production-гілкою `main`. Сам файл конфігурації
не створює підключення до GitHub і не змінює налаштування домену.
