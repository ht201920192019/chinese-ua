# Chinese UA

Статичний навчальний сайт китайської мови для україномовних учнів.
Основний домен: https://chinese-ua.pp.ua/.

## Джерела та сторінки

- `src/site-data.cjs` — навчальні дані: курси, слова, граматика, діалоги й тематичні сторінки.
- `scripts/build-site.cjs` — шаблони та генератор статичних HTML-сторінок, sitemap і перенаправлень.
- `public/` — готовий сайт, який публікується Cloudflare Workers Static Assets.
- `public/styles.css` і `public/script.js` — адаптивний дизайн, меню, озвучення й копіювання.
- `public/_redirects` — перенаправлення старих URL `.html` на нову структуру.
- `tests/browser.cjs` — перевірка сторінок у Microsoft Edge через Playwright.

Після редагування матеріалів перебудуйте сторінки командою `npm run build` і додайте згенеровані файли з `public/` до Git. Генератор не має зовнішніх залежностей; сайт працює як звичайний HTML/CSS/JavaScript без запуску генератора на сервері.

## Локальний перегляд

Після `npm run build` запустіть `python -m http.server 8000 --directory public` та відкрийте http://localhost:8000. Для URL з кінцевою скісною рискою вебсервер має віддавати відповідний `index.html`.

## Перевірки

`npm test` перевіряє всі згенеровані сторінки, SEO-метадані, sitemap, старі URL, внутрішні посилання, мобільні ширини, меню, копіювання та кнопки озвучення. Для тесту потрібні Node.js, Playwright і Microsoft Edge; ці інструменти не потрапляють до сайту.

Озвучення залежить від наявності китайського голосу в браузері або системі. Якщо голосу немає, Pinyin та український переклад залишаються доступними.

## Cloudflare Workers

Worker: `red-breeze-15ec`. Конфігурація `wrangler.jsonc` публікує `./public`; сумісність і структура Worker залишаються без змін. GitHub-інтеграція має використовувати production-гілку `main`. Після `npm run build` згенеровані файли комітяться, тому Cloudflare може публікувати їх без кроку збірки.

## Google Search

У `public/robots.txt` вказано sitemap, який генератор будує з усіх маршрутів. Після публікації перевірте `https://chinese-ua.pp.ua/robots.txt` і `https://chinese-ua.pp.ua/sitemap.xml` у Google Search Console. Подання карти сайту не гарантує індексацію чи позицію в результатах пошуку.
