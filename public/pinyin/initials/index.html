Ініціалі китайської мови

Ініціаль — початковий приголосний складy Pinyin. Для україномовних учнів особливо важливо розрізняти пари z/c/s та zh/ch/sh, а також j/q/x.

Навігація по сторінці 3 розділів
Що тренуватиСкладні для україномовних звукиМінімальні пари

Що тренувати

Промовляйте звук разом із голосною: zhā, chá, shā. Не додавайте після приголосного окремий український голосний звук.

Складні для україномовних звуки

zh, ch, sh вимовляються з язиком, відведеним трохи назад. j, q, x утворюються ближче до передньої частини піднебіння; q має сильний видих. r у Pinyin не дорівнює українському р.

Мінімальні пари

zā / zhā · cā / chā · sān / shān. Слухайте різницю й повторюйте короткими серіями, не покладаючись на кириличний запис.
