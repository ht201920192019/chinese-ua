2. Граматика

有 yǒu означає «мати / є». Для кількості людей скажіть: 我家有 + число + 个 + 人. У 个 читання ge нейтральне.

3. Діалог

A你家有几个人？Nǐ jiā yǒu jǐ ge rén?Скільки людей у твоїй сім’ї?
B我家有四个人。Wǒ jiā yǒu sì ge rén.У моїй сім’ї четверо людей.
A你有姐姐吗？Nǐ yǒu jiějie ma?У тебе є старша сестра?

4. Вимова

У китайській назви старшого й молодшого брата/сестри відрізняються. Повторюйте склад зі знаком тону: gēge, jiějie, dìdi.
